# Telegram-канали міст

П'ять публічних каналів, які пошук Telegram знаходить за назвою («куди піти одеса»). Генератор
`tools/telegram_post.mjs` щодня близько 12:00 постить події міста на сьогодні, що ще не почались, а щоп'ятниці ще й
вихідні. Кожна подія веде на `poriad.app/e/{id}`, рядок унизу веде на `poriad.app/app?from=tg…`. Розклад —
`.github/workflows/telegram.yml`.

## 1. Канали

Telegram → «Новий канал», п'ять разів:

| Місто  | Назва                       | secret                     | мітка `from` |
|--------|-----------------------------|----------------------------|--------------|
| Київ   | Куди піти в Києві · Поряд   | `TELEGRAM_CHANNEL_KYIV`    | `tgk`        |
| Львів  | Куди піти у Львові · Поряд  | `TELEGRAM_CHANNEL_LVIV`    | `tgl`        |
| Одеса  | Куди піти в Одесі · Поряд   | `TELEGRAM_CHANNEL_ODESA`   | `tgo`        |
| Дніпро | Куди піти в Дніпрі · Поряд  | `TELEGRAM_CHANNEL_DNIPRO`  | `tgd`        |
| Харків | Куди піти в Харкові · Поряд | `TELEGRAM_CHANNEL_KHARKIV` | `tgh`        |

- Тип **публічний**, бо в пошуку видно лише публічні. Посилання (username) латиницею, наприклад `kudy_piti_odesa`.
  Зайнятість Telegram покаже одразу.
- Аватар — іконка застосунку. Опис, наприклад: «Що сьогодні й на вихідних в Одесі. Уся афіша міста на мапі:
  poriad.app/app?from=tgo» (мітка свого міста).

## 2. Бот

1. @BotFather → `/newbot`. Ім'я «Поряд», username має закінчуватись на `bot`, наприклад `poriad_afisha_bot`.
2. BotFather віддасть токен `123456:ABC…`. Це пароль: нікуди не вставляти, крім secret нижче. Якщо витік, у
   BotFather `/revoke`, і заново в secret.

## 3. Бот — адмін кожного каналу

Канал → «Керувати каналом» → «Адміністратори» → «Додати адміністратора» → знайти бота за username. Лишити тільки
«Публікувати повідомлення», решту вимкнути.

## 4. Secrets

GitHub → репозиторій → Settings → Secrets and variables → Actions → New repository secret:

- `TELEGRAM_BOT_TOKEN`: токен із BotFather;
- `TELEGRAM_CHANNEL_KYIV` … `TELEGRAM_CHANNEL_KHARKIV`: `@username` каналу (з `@`).

Або з терміналу, токен спитає сам:

```bash
gh secret set TELEGRAM_BOT_TOKEN
```

Місто без secret генератор пропускає, тож можна почати з одного каналу.

## 5. Перевірка

- Локально, без надсилання: `node tools/telegram_post.mjs today --dry-run` (або `weekend`, `--city Одеса`).
- GitHub → Actions → telegram → Run workflow: з галочкою `dry_run` пости лише в лозі, без неї йде справжній пост.

Розклад запрацює, коли `telegram.yml` буде в `main` на GitHub. GitHub запускає його із запізненням (див. коментар у
workflow), тож за перший тиждень варто глянути, о котрій пости реально виходять, і за потреби зсунути cron.

Що в пості: обкладинка (картинка першої події з фото), рядок «Сьогодні в Києві є куди піти: вистави, концерти і
стендап 👇» і 5–7 подій на сьогодні або 8–10 на вихідні (по днях): емодзі категорії, час, назва-посилання, заклад і
ціна. Різні категорії, один заклад на день, «Від людей» гарантовано. Афіша та сама, що бачить гість у застосунку. «Безкоштовно» пишеться лише для подій від людей і з
Concert.ua та Karabas (`FREE_TRUSTED` у генераторі), і лише коли жоден продавець події не просить грошей.
