# In-App Events в App Store

Навіщо: App Store сам показує подію тим, хто давно не відкривав застосунок, якщо мета — «Bring back lapsed users»
([бриф утримання](../docs/retention-brief-2026-10.md), §6 і §8, п. 9). Безкоштовно, без коду. Незалежних даних про
ефект нема — пробуємо й дивимось у ASC → Analytics → In-App Events.

Де: App Store Connect → застосунок → **In-App Events** → «+». Мова — українська (Ukrainian), інших локалізацій у нас нема.

## Правила Apple, на яких найчастіше відмовляють

- Подія — обмежена в часі й прив'язана до **нового** контенту чи функції. «Загальна промоція застосунку»,
  щоденні дії й знижки без нового контенту — відмова.
- У назві й описах — без капсу, «!!», «найкращий», цін і валют («від 300 ₴» — відмова), без заклику як назви.
- У медіа — **без тексту й логотипів**, без рамок і градієнтів; лише власні зображення.
- Ліміти: назва 30, короткий опис 50, довгий 120 знаків; до 31 дня; анонс за ≤14 днів до старту; до 10
  опублікованих одночасно.
- Медіа: картка 16:9 (від 1920×1080, JPG/PNG або відео 30/60 fps), сторінка події 9:16 (від 1080×1920).

## Подія 1 — запуск «Шукаю компанію»

Ставити, щойно в App Store вийде збірка з «Шукаю компанію» (1.3.0).

| Поле | Значення |
|---|---|
| Reference name | `companions-launch` |
| Badge | Major Update |
| Purpose | Bring back lapsed users |
| Назва (28/30) | Не йди сам: «Шукаю компанію» |
| Короткий опис (42/50) | Знайдіть, з ким піти на концерт чи виставу |
| Довгий опис (97/120) | На будь-яку подію з афіші натисніть «Шукаю компанію» — до вас приєднаються ті, хто теж хоче піти. |
| Початок / кінець | день виходу збірки → +30 днів |
| Анонс | за 7 днів до початку (можна до 14) |
| Deep link | порожньо (див. нижче) |

## Подія 2 — зимові свята

| Поле | Значення |
|---|---|
| Reference name | `winter-holidays-2026` |
| Badge | Special Event |
| Purpose | Bring back lapsed users |
| Назва (20/30) | Зимові свята в місті |
| Короткий опис (41/50) | Ярмарки, ялинки й вистави для дітей поруч |
| Довгий опис (108/120) | Новорічні концерти, ярмарки й дитячі вистави вашого міста на одній мапі. Нема з ким піти — «Шукаю компанію». |
| Початок / кінець | 2026-12-01 → 2026-12-31 (31 день) |
| Анонс | з 2026-11-17 (14 днів) |
| Deep link | порожньо |

Ризик: Apple може вважати це загальною промоцією. Аргумент для App Review — новий сезонний контент: у грудні в
афіші з'являються ярмарки й новорічні вистави, яких зараз нема (категорія «Дітям»). Перед поданням перевірити, що
їх справді імпортовано, а «Шукаю компанію» до того часу вже в сторі.

## Медіа (потрібно зробити)

Для кожної події — картка 1920×1080 і сторінка 1080×1920, **без тексту**. Напрям — квитки «Корінця» зі скрінів
сторів (`tools/store_shots.py`, DESIGN.md), але без написів: для події 1 — два корінці квитків поруч, для події 2 — квиток
на тлі вечірнього міста з вогниками. Можна зробити тим самим скриптом або в Claude Design.

## Deep link

Universal Links зараз відкривають лише `/e/*` (`worker/index.mjs`, `appleAssociation()`), а екрана «зимові свята» в
застосунку нема. Без посилання кнопка «Відкрити» просто запускає застосунок — на головну з «У місті», цього досить.
Якщо Apple попросить посилання: додати в AASA шлях `/afisha*` і обробку в застосунку (окрема задача).
