# Гібрид: motion design + справжній інтерфейс (v3)

32.7 с, 9:16, 30 fps. Композиція `Hybrid` (`video/src/Hybrid.tsx`), рендери `video/out/hybrid-{master,silent}.mp4`; v1 (34 с) — `out/hybrid-v1.mp4`.

**Правила** (фідбек «хук слабкий, текст не відповідає кадру» + бренд-ревʼю 09.10):
1. Один кадр — одне твердження — один доказ. Підпис змінюється разом з інтерфейсом (компонент `Captions`).
2. Біль — motion design, рішення — живий інтерфейс.
3. Хук — пошукова фраза + **одна цифра, яку видно в застосунку в цьому ж ролику** (prod).
4. Інтерфейс — з prod (`clips/prod/`). Де prod-даних нема (пошуки компанії, події від людей) — dev з позначкою «приклад»; для платної реклами ці сцени треба перезняти на prod.
5. Голос без роду, без тверджень про повноту, назва «Поряд» з великої з іконкою з першої секунди, наприкінці — офіційний бейдж App Store.

| Час | Тип | Підпис | Що в кадрі |

| 4.6–5.7 с | motion | [іконка] **Поряд** збирає їх **на одну мапу** | Картки й піни стягуються в один коралевий пін, камера пірнає в нього |
| 5.7–9.2 с | UI prod | **Поряд** збирає їх на одну мапу → тапаєш «Вихідні» — **151 подія** | Пін стає екраном: уся мапа Києва (1032), тап «Вихідні» → вилітає «Знайдено подій: 151» |

| 14.7–18.7 с | UI dev, «приклад» | на афіші — **шукаю компанію** → ті, хто теж без компанії. **тисни «Долучитися»** | Скрол до «Шукають компанію», вилітають картка «1 з 5 · Долучитися» і кнопка |

| 29.5–32.7 с | motion | **поряд** · твоє місто. нарешті видно. · безкоштовно + офіційний бейдж App Store | Знак; рядок про торговельні марки Apple |

**151** — фільтр «Вихідні» на мапі Києва в prod-збірці 09.10 (`clips/prod/weekend.mov`). Перед кожним рендером: перезняти цей кліп, оновити `WEEKEND` у `Hybrid.tsx` (хук округлюється вниз до 50: «150+»).

Музика: `music/calm.m4a` (Sonilo, 32 с, 2 кредити) — спокійний трек без дропів: тихіший вступ під хук, рівна основна частина, затихає під логотип. Попередній `brand.m4a` користувач назвав «занадто активним».
